# Code Style and Conventions

## Python Style Guidelines
- Follow PEP 8 standards for Python code
- Use meaningful variable names in English
- Use snake_case for functions and variables
- Use PascalCase for classes

## Streamlit Specific Conventions
- Use `st.` prefix for all Streamlit components
- Structure apps with clear sections using `st.header()` and `st.subheader()`
- Use columns (`st.columns()`) for layout when needed
- Provide user-friendly labels for all input widgets

## Documentation
- Add docstrings for functions and classes
- Use inline comments for complex logic
- Include Japanese comments where appropriate for educational content

## File Structure
- Main application in `streamlit_app.py`
- Keep dependencies minimal and list in `requirements.txt`
- Use meaningful commit messages in Japanese/English mix as needed

## User Interface Guidelines
- Make interfaces intuitive and educational
- Use emojis and icons to make content engaging
- Provide clear instructions and explanations
- Use progress bars and visual feedback for better UX
