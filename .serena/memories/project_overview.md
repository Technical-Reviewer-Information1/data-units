# Data Units Conversion Project

## Purpose
This project is a Streamlit web application designed to help users learn and visualize information unit conversions (Byte, KB, MB, GB, TB). The app provides an interactive educational experience with two main parts:

1. **Unit Conversion Calculator**: Interactive tool for converting between different data units
2. **Storage Capacity Checker**: Practical simulation tool to check if files fit in storage

## Target Audience
Students and anyone learning about computer data units and storage concepts.

## Educational Goals
- Teach the relationship between data units (1024 conversion factor)
- Provide hands-on experience with storage capacity planning
- Make abstract concepts concrete through interactive visualization

## Key Features
- Real-time unit conversion with detailed explanations
- Storage capacity simulation with multiple file types
- Progress bars and visual feedback
- Educational tips and explanations
